Picku (Pet Adoption Website) 

Live : https://picku-a-pet-adoption-website.netlify.app/login.html

Github : https://github.com/MuhammadIktear/Picku-a-pet-adoption-website

Description : Picku is a user-friendly pet adoption website that connects pets in need 
with loving homes. Users can browse available pets, create and manage pet listings, and 
leave reviews for adopted pets. The platform offers seamless account management, including 
profile updates, secure password changes, and support via About and Contact pages. Picku makes 
pet adoption simple, secure, and accessible.


Features :
Sign up / Login, View All Pets, Profile Management, Create Pet, Edit / Delete Pet, Review,
Edit Profile, Password Change, About Us / Contact Us, Logout, and more.


Technology :
Frontend- HTML, CSS, JavaScript, Bootstrap 5

Backend- Django, Django REST Framework

Database- SQLite (Django default)
